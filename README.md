# Python Curso em Vídeo Community

Bem-vindo ao Python Curso em Vídeo Community! 🚀

Este repositório foi criado para ajudar estudantes de Python a praticarem Git e GitHub enquanto resolvem os exercícios do curso de Python do Curso em Vídeo.

Se você gostou do projeto, não esqueça de dar uma estrela ⭐ e compartilhar com seus amigos.

## Aviso

Este é um projeto independente criado pela comunidade para fins educacionais.

Não possui vínculo oficial com o Curso em Vídeo ou seus criadores.

## Objetivo

A proposta é simples:

* Resolver os exercícios do curso.
* Praticar Git e GitHub em projetos reais.
* Aprender a colaborar em um projeto open source.
* Compartilhar diferentes soluções para o mesmo problema.

## Como Participar
### 1. Faça um Fork deste repositório.
Forque este repositório clicando no botão **FORK** na parte superior desta página. Isso criará uma cópia deste repositório na sua conta.
<img width="1262" height="81" alt="Captura de tela de 2026-08-12 18-56-55" src="https://github.com/user-attachments/assets/6cd55f13-1059-4f1c-bd83-e89fefe06bb1" />
***
### 2. Clone o Fork para sua máquina.
Agora clone o repositório bifurcado para sua máquina. Vá para a sua conta do GitHub, abra o repositório bifurcado, clique no botão de código e, em seguida, na guia SSH e clique no ícone copiar url para área de transferência.
<img width="923" height="426" alt="Captura de tela de 2026-08-12 19-10-36" src="https://github.com/user-attachments/assets/f454ba34-abbe-4308-90b3-efe01edc9a80" />

Abra um terminal e execute o seguinte comando git:

```
git clone "url copiado"
```
Por exemplo:
```
git clone git@github.com:SEU-NOME/python-curso-em-video-community.git
```
Onde "url copiado" (sem as aspas) é o url ssh para este repositório. Aqui você está copiando o conteúdo do repositório no GitHub para o seu computador.
***
### 3. Criando uma branch
Altere para o diretório do repositório no seu computador (se você ainda não estiver lá):

Abra o diretório:
```
cd python-curso-em-video-community
```
Crie uma branch com:
```
git checkout -b sua-branch
```
Por exemplo:
```
git checkout -b add-jose
```
***
### 4. Faça as alterações necessárias e comprometa essas alterações
Agora que você está na sua branch, escolha o Mundo que você está estudando.

<img width="384" height="312" alt="image" src="https://github.com/user-attachments/assets/3e5cdb15-5b27-4b57-9761-2424778b3bc6" />

Crie sua pasta dentro do Mundo e faça sua solução para os exercícios.

**🔴 ATENÇÃO: O NOME DA PASTA PRECISA SER SEU NOME DE USUÁRIO PARA EVITAR CONFLITOS**

<img width="986" height="444" alt="Captura de tela de 2026-08-12 20-42-56" src="https://github.com/user-attachments/assets/d1599391-c627-47cf-86c1-8e8936e82b8e" />

***
### 5. ADD e COMMIT
Adicione essas alterações a branch que você acabou de criar usando o `git add`: (substitua "jose" pelo seu nome)
```
git add add-jose/
```
Agora comprometa essas alterações usando o `git commit`:
```
git commit -m 'add 'seu-nome' a lista de exercícios'
```
***
### 6. Push para o GitHub
Empurre suas alterações usando o comando `git push`: (substitua "sua-branch" pela que você criou no passo 3)
```
git push -u origin sua-branch
```
***
### 7. Envie suas alterações
No seu repositório do GitHub, vá na aba de **Pull requests** e clique em **New pull request**
<img width="1568" height="424" alt="Captura de tela de 2026-08-12 20-05-41" src="https://github.com/user-attachments/assets/5cdda6dd-c021-42fc-b1d7-903fa44101bd" />

1 - Selecione a branch master do projeto, para onde você vai mandar sua branch

2 - Selecione a branch que você criou no passo 3

3 - Crie sua solicitação de pull request
<img width="1270" height="367" alt="Captura de tela de 2026-08-12 20-08-05" src="https://github.com/user-attachments/assets/2a090896-0cb2-4114-be48-bd26001988fa" />

Em breve estarei mesclando todas as suas mudanças no ramo principal deste projeto.

## Regras

* Mantenha a estrutura de pastas do projeto.
* Envie apenas soluções próprias.
* Utilize nomes de arquivos claros e organizados.
* Respeite os demais participantes.
* Não altere arquivos de outros colaboradores sem necessidade.

## Para Iniciantes

Se você nunca utilizou Git ou GitHub, este projeto é um ótimo lugar para aprender:

* Como fazer um Fork.
* Como clonar um repositório.
* Como criar Commits.
* Como abrir um Pull Request.
* Como colaborar em projetos open source.

Não tenha medo de errar. O objetivo é aprender juntos. 💙
